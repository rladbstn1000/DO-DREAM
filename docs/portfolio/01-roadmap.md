## 2026-09-30 목표 변경

코드 최종 점검은 18 문서에 보존하고, 최신 작업은 서버 없는 정적 showcase 구현·실제 브라우저 인수·산출물 검토·문서화·로컬 커밋이다. 실제 AI 공급자 호출, 모델 품질 평가와 비용 측정은 현재 완료 조건에서 제외한다. 기존 adapter·오프라인 계약 검사·고정 평가셋은 비활성 상태로 보존하며, 키가 없어도 코드 개선과 공개 정적 데모 준비를 진행할 수 있다. 아래 1~5단계 결과와 실패·NOT_RUN 판정은 당시 기록으로 유지한다.

실제 백엔드 통합 실행의 기본은 키 없는 `LOCAL_FAKE`다. 공개 showcase는 서버 없이 별도로 실행한다. 키 존재로 live를 자동 활성화하거나 실제 API 실패를 대역 성공으로 바꾸지 않는다. 실제 AI는 선택적인 별도 후속 작업이며 `REAL_AI_INTEGRATION=NOT_RUN`이다. 공개 정적 데모를 구현하되 GitHub 배포·push에는 착수하지 않는다.
